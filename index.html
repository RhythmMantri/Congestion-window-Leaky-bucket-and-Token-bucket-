About the Algorithms

TCP Tahoe

Implementation of slow start, congestion avoidance, and fast retransmit.

TCP Reno

Includes all Tahoe features plus fast recovery algorithm.

TCP CUBIC

Uses a cubic function instead of linear growth for congestion avoidance.

Leaky Bucket

Outputs packets at a constant rate, smoothing bursty traffic.

Token Bucket

Allows bursts of traffic up to a limit, controlled by token generation.
